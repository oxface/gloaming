# Checkpointed Access database fixture

`Access-20a02be.sql` is the native EF Core 10.0.12 migration script generated from the
owner-reviewed `20a02be` HTTP sample before E3.4 moved its Access module. It contains migration
`20261005204257_InitialAccess` and its original history table. No current-model seed or
Inventory schema is included.

The compatibility proof applies this retained SQL to a fresh PostgreSQL database, adds
independent identity/admission witnesses, and then invokes the relocated native migrations.
This prevents testing only a database freshly generated by the current relocated model.
Do not regenerate this baseline to make a future compatibility failure pass.
